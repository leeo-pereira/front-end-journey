# Front-end Journey  
### Estudos práticos em HTML, CSS e JavaScript

Este repositório reúne **projetos e exercícios desenvolvidos durante meus estudos em Front-end**, com foco em fundamentos, lógica de programação e boas práticas de organização de código.

A ideia aqui não é criar projetos finais ou produtos completos, mas **registrar o processo de aprendizado**, documentando decisões, experimentos e aprendizados ao longo do caminho.

🔗 https://leeo-pereira.github.io/front-end-journey/

---

## 🎯 Objetivo do Repositório

- Consolidar fundamentos de **HTML semântico**, **CSS moderno** e **JavaScript**
- Praticar organização de código e estrutura de pastas
- Explorar responsividade, layout e comportamento de interfaces
- Criar uma base sólida para projetos mais complexos no futuro

## 🧪 Projeto Atual

### Landing Page — Estudo de Front-end

Estudo prático focado na construção de uma landing page responsiva, explorando:

- Estruturação com HTML semântico  
- Layouts responsivos utilizando CSS Grid e Flexbox  
- Organização e reutilização de estilos  
- Primeiros usos de JavaScript para manipulação de conteúdo  

📌 O projeto inclui um README próprio com contexto, objetivos e aprendizados.

Este estudo se conecta a um projeto mais completo de aplicação prática em Front-end, focado em UX e produto:
👉 [Landing Page — Estudo de Front-end com foco em UX e Produto](https://github.com/leeo-pereira/orcafascio-remake)
